# depviz — визуализатор графа зависимостей apt (вариант 26)

Один файл `main.cpp`, без сторонних библиотек. Индекс пакетов
скачивается через `curl` и разбирается вручную.

## Сборка

```bash
g++ -std=c++17 -Wall -Wextra -o depviz main.cpp
```

## Параметры

| Опция | Значение |
|---|---|
| `--package NAME` | имя анализируемого пакета |
| `--repo URL_OR_PATH` | URL файла `Packages(.gz)` или путь к тестовому файлу |
| `--test-mode` | режим тестового репозитория |
| `--ascii-tree` | вывод зависимостей в виде ASCII-дерева |
| `--filter SUBSTRING` | не учитывать пакеты, имя которых содержит подстроку |

Пример реального репозитория:

```bash
./depviz --package curl --repo http://archive.ubuntu.com/ubuntu/dists/jammy/main/binary-amd64/Packages.gz
```

Тестовый репозиторий — файл `test_repo.txt`, строки вида `A: B C`.

```bash
./depviz --test-mode --repo test_repo.txt --package A
```

## Порядок загрузки и сравнение с apt (этап 4)

Порядок загрузки — порядок завершения обхода в глубину: пакет
выводится после всех своих зависимостей. Для `curl` (jammy, main)
первыми идут `gcc-12-base`, `libgcc-s1`, `libcrypt1`, `libc6`,
последними — `libcurl4`, `curl`.

Реальный менеджер (`apt-get install --simulate curl`) выдаст другой
результат. Причины:

1. apt ставит только недостающие пакеты. В системе почти всегда уже
   есть `libc6`, `dpkg`, `tar`, `perl-base`, поэтому в его выводе
   будут 2–5 пакетов, а не 42.
2. apt выбирает вариант из альтернатив `a | b` по тому, что уже
   установлено. depviz всегда берёт первый вариант.
3. apt учитывает версии (`>= 2.34`), `Provides`, виртуальные пакеты,
   `Conflicts`/`Breaks`, а также по умолчанию `Recommends`. depviz
   учитывает только `Depends` и `Pre-Depends` без версий.
4. При циклах (`libc6 <-> libgcc-s1`) apt/dpkg распаковывают пакеты
   цикла вместе и настраивают их одной группой. depviz просто
   разрывает цикл на обратном ребре, поэтому порядок внутри цикла
   может отличаться.
5. Порядок пакетов без зависимостей между собой у apt определяется
   его внутренней сортировкой, а у depviz — порядком в поле
   `Depends`.
