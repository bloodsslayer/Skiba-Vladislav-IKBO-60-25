# Транслятор конфигураций в TOML

Программа читает конфигурацию из стандартного ввода и записывает TOML
в файл, указанный ключом `-o`. Весь код программы находится в
`src/main.cpp` и использует стандартную библиотеку C++.

## Сборка и запуск

Для сборки нужен компилятор с поддержкой C++17.
Make запускает сборку и тесты.
Для тестов нужен Python 3.11 или новее.

```sh
make
./build/config-to-toml -o result.toml < input.txt
make test
make clean
```

Собрать программу напрямую компилятором можно так.

```sh
mkdir -p build
c++ -std=c++17 src/main.cpp -o build/config-to-toml
```

В `input.txt` уже есть пример для запуска. Свои конфигурации сохраняйте в кодировке UTF-8.
`make test` запускает транслятор и проверяет результат TOML через
стандартный модуль Python `tomllib`. В тесты входят все три примера ниже.
При сборке можно переопределить `CXX`, `CPPFLAGS` и `CXXFLAGS`,
а для тестов указать интерпретатор через `PYTHON`.

## Синтаксис

- В документе один корневой словарь. Перед ним можно объявлять константы.
- Имена состоят из одной или нескольких строчных латинских букв `[a-z]+`.
- Числа записываются с целой и дробной частями через точку.
  Допустимы знаки `+` и `-`. Лишние ведущие нули убираются при записи TOML.
- Строка начинается с `@"` и заканчивается ближайшей кавычкой `"`.
  Обратная косая черта во входной строке считается обычным символом.
- Словарь записывается как `table(ключ => значение, ...)`. Разрешены пустой
  словарь `table()`, вложенные словари и запятая после последнего поля.
  Имена ключей внутри одного словаря должны быть уникальны.
- `(def имя значение)` объявляет константу, а `$имя$` подставляет её
  значение. Константа может хранить число, строку или словарь.
  Константы объявляются до первого обращения к ним, имена уникальны.
  В корне можно использовать ссылку на константу со словарём.

Корневые поля записываются как строки `ключ = значение`. Вложенные
словари записываются как встроенные таблицы `{ключ = значение}`.
Поля в каждой таблице выводятся в алфавитном порядке.

## Как устроен код

- `Parser::parse` читает объявления констант и корневой словарь.
  `parseDefinition` сохраняет константу, а `parseReference` находит её значение.
- `parseValue` определяет вид значения по первому символу. `parseNumber`
  и `parseString` читают простые значения, а `parseTable` разбирает поля,
  вызывая `parseValue` для каждого из них.
- `readRun`, `readName` и `skipSpace` читают группы символов. `consume`
  проверяет разделитель, `expect` требует его, а `fail` сообщает об ошибке
  с позицией. `store` сохраняет разобранное значение для последующего вывода.
- `normalizeNumber` убирает лишние ведущие нули, а `quoteString` экранирует
  строку по правилам TOML. `writeToml` открывает файл и записывает корневые
  поля, используя `writeValue` для значений.
- `main` проверяет аргументы, читает ввод и запускает трансляцию.

Код завершения `0` означает успех, `1` означает ошибку ввода или записи,
`2` означает неверные аргументы. Ошибки выводятся в `stderr`.
Позиция во входе указывается в формате `строка:столбец` с отсчётом от 1.
Столбец считается в байтах UTF-8. Выходной файл открывается после успешного
разбора, поэтому при ошибке во входном тексте существующий файл сохраняется.

## Примеры

### Веб-сервис

```text
(def timeout +003.5)
table(
    service => @"Каталог",
    network => table(host => @"localhost", timeout => $timeout$),
)
```

```toml
network = {host = "localhost", timeout = +3.5}
service = "Каталог"
```

### Метеостанция

```text
(def calibration table(offset => -1.25, scale => 1.05))
table(
    outside => table(sensor => @"Термометр", calibration => $calibration$),
    station => @"Северная",
)
```

```toml
outside = {calibration = {offset = -1.25, scale = 1.05}, sensor = "Термометр"}
station = "Северная"
```

### Библиотека

```text
(def branch @"Центральная")
(def defaults table(branch => $branch$, limits => table(loan => 14.0)))
table(
    catalog => $defaults$,
    reservations => table(),
)
```

```toml
catalog = {branch = "Центральная", limits = {loan = 14.0}}
reservations = {}
```
