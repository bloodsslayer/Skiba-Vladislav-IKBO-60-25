# Эмулятор командной оболочки UNIX (вариант 26)

Эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом.
Написан на C++, весь код в одном файле `main.cpp`, GUI сделан на [FLTK](https://www.fltk.org).

## Установка FLTK

```bash
brew install fltk                 # macOS
sudo apt install libfltk1.3-dev   # Ubuntu / Debian
```

## Сборка

```bash
./build.sh
```

## Запуск

```bash
./emulator [--vfs <путь к JSON>] [--script <путь к скрипту>]
```

- `--vfs` — файл с виртуальной файловой системой
- `--script` — стартовый скрипт, выполняется сразу после запуска

Пример:

```bash
./emulator --vfs vfs/deep.json --script scripts/full.txt
```

## Команды

| Команда | Описание |
|---|---|
| `ls [путь]` | содержимое папки (папки выводятся с `/` на конце) |
| `cd [путь]` | перейти в папку; без аргумента — в корень |
| `exit [код]` | выйти из эмулятора с кодом возврата |

Пути бывают абсолютные (`/home/user`) и относительные (`../etc`), поддерживаются `.` и `..`.
Аргументы с пробелами пишутся в кавычках: `cd "my folder"` или `cd 'my folder'`.

## Формат VFS

VFS — это JSON-файл. Объект — папка, строка — файл, содержимое файла хранится в base64:

```json
{
  "home": {
    "readme.txt": "SGVsbG8sIFZGUyEK"
  },
  "tmp": {}
}
```

VFS целиком загружается в память, исходный файл не изменяется.

## Стартовый скрипт

Обычный текстовый файл, одна команда на строку. Строки, начинающиеся с `//`, — комментарии.
При выполнении на экране видны и команды, и их вывод. При ошибке выводится номер строки, и скрипт продолжает работу.

```
// перейти в домашнюю папку
cd /home/user
ls
```

## Структура проекта

```
main.cpp     весь код эмулятора
build.sh     сборка
scripts/     стартовые скрипты (start.txt — этап 2, full.txt — все команды и ошибки)
vfs/         примеры VFS: minimal, files, deep (5 уровней), broken (некорректный JSON)
tests/       скрипты ОС для запуска эмулятора с разными параметрами и VFS
```

## Тесты

```bash
./tests/test_params.sh       # все варианты параметров командной строки
./tests/test_errors.sh       # ошибки в параметрах
./tests/test_vfs_minimal.sh  # пустая VFS
./tests/test_vfs_files.sh    # VFS с несколькими файлами
./tests/test_vfs_deep.sh     # VFS с глубокой вложенностью
./tests/test_vfs_errors.sh   # ошибки загрузки VFS
```

Тесты открывают окно эмулятора. Закройте окно или введите `exit`, чтобы перейти к следующему запуску.
